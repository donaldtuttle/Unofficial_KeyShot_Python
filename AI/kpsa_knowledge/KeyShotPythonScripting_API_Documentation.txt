# KeyShot Python Scripting API Reference (Thin Layer)

**Target:** KeyShot Studio 2026.2

**API source of truth:** `lux/KeyShot_lux_API.md` — `help(lux)` from the 2026.2 console. This file is a pointer only. If it disagrees with the dump, the dump is correct.

Do not prefer the public 2026.1 website over the dump. It lags.

## Thin notes

- `SceneNode.getMetadata()` is in the 2026.2 dump.
- `lux.renderAnimation()` is in the dump and is the preferred animation render path.
- Node IDs are dynamic and session-unstable. Prefer names and re-query after graph operations.
- No `lux.getActiveCamera()` — use `lux.getCamera()` / `lux.getCameras()`.
- No `lux.getMaterial()` / `lux.getMaterials()` — use `lux.getMaterialGraph(name)` and `lux.getSceneMaterials()`.
- No `lux.beginUndoSession()` / `lux.endUndoSession()` in the 2026.2 dump. Do not use them.
- No `lux.getAnimations()` / `lux.getNodeAnimations()`.

## Common patterns

- Material graph: `graph = lux.getMaterialGraph(name="name"); if graph: ...`
- Dialog: complete tuples, check cancellation, GUI only (`if not lux.isHeadless()`).
- Matrices: start from identity, then translate / rotate / scale.
- Always check `None` and empty lists before use.

See `AI/constraints.md` for hard rules.
