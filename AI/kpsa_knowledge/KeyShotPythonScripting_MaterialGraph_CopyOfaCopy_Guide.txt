## 1. What the second pass is for

Keep the post-copy connection pass. Its purpose is to establish that the
intended copied nodes are connected to the intended target inputs using their
current IDs. A successful create/copy/newEdge call does not establish this.
Do not remove the pass because a copy API appears to do similar work.

Node names may be empty, and different nodes may have the same name. Use names
as readable labels; do not select a connection endpoint by the first name match.
Record the actual source-to-copy correspondence while copying, then read back
and verify every connection. A second-generation copy needs its own current
mapping from the first copy to the second copy.

The earlier v1.3.6 listing combined native material copying, manual node
reconstruction and edge creation, then printed success without a complete
read-back check. This revision supplies the missing explicit verification pass.
It does not declare the established manual pass redundant, and it does not
replace a tested reconstruction workflow with an assumed equivalent operation.

## 2. Names, IDs and Multi-Material roots

DT's runtime observation: node/material IDs are reassigned when a scene is
reopened. They distinguish currently loaded items that can share display names.
IDs must not be persisted as stable identifiers across reopening. Refresh
references after copying/linking; an old mapping is not valid merely because
the names still look familiar. Compare IDs within the intended graph/session;
different numeric IDs alone do not prove that two materials are independent.

- Get the parent MaterialGraph using its resolved API material name.
- MaterialGraph.getMaterialNodes() returns the individual sub-material root
  ShaderNodes of a Multi-Material. For an ordinary material it returns one root.
- Read each root's getName(), getType() and getID(). An empty name is not an error.
- MultiMaterial.getSubMaterials() supplies ordered sub-material metadata. Do not
  zip that list with getMaterialNodes() and assume matching positions.
- A single material root does not prove that a material is not a Multi-Material.
- Inspect each root's upstream nodes and edges in its parent graph. A separate
  getMaterialGraph(name) lookup is appropriate only if that sub-material has a
  valid, unambiguous API name. Do not turn an unnamed root into a guessed name.
- Include detached nodes in an all-node copy check. No automatic node cleanup
  belongs in verification.

ShaderNode.getType() is handled as {'name': ..., 'display_name': ...} in the
repository's Information Inspector and OpenPBR converter. Preserve its raw
value for diagnosis; use the internal shader type when a shader type is needed.
A display label is not a shader creation identifier.

## 3. Copy operations and their boundaries

The documented native operation is lux.createMultiMaterial(name, mat). It creates
a new Multi-Material based on an existing material. Both arguments are required.
If mat is a list, the capture says the FIRST entry is used as the cloning source;
that list is not a documented instruction to copy every listed sub-material.

The following is an API integration fragment, not a complete copying script.
source_name and copy_name must already be resolved by the caller, and copy_name
must be a new unused name. Existing scene assignments are not part of this step.

```python
import lux

lux.createMultiMaterial(name=copy_name, mat=source_name)
copied_graph = lux.getMaterialGraph(name=copy_name)
if copied_graph is None:
    raise RuntimeError("The requested copied material graph could not be retrieved")
```

The capture does not establish a complete return-value contract for
createMultiMaterial(). Do not interpret a None return from that call alone as
failure. Retrieve and inspect the resulting graph. Do not print "fully
independent copy" merely because a graph or new IDs exist.

There is no MaterialGraph.clone() declaration in the selected capture. Python
copy/deepcopy is not a documented material-graph copying facility. The word
"clone" in the createMultiMaterial docstring does not add a graph.clone method.

Manual reconstruction remains a distinct operation. When it is part of the
working workflow, preserve its node creation, concrete-value copying and edge
reconnection stages, and retain their source-to-copy correspondence. Do not
create another set of nodes as an accidental substitute for verification.
Root/container nodes require explicit destination-root correspondence; do not
feed an internal root type into newNode() as if it were an ordinary shader.

Adding a copied sub-material to another Multi-Material is a later mutation.
Resolve the exact sub-material and destination, preserve the existing ordered
list and active selection, perform the intended setSubMaterials operation,
then re-query the graphs and verify again. The capture does not establish
arbitrary nested Multi-Material support, so do not blindly append a newly
created container's name as though it were a verified leaf sub-material.

## 4. Mandatory verification contract

The copying stage must provide a current source-node-ID -> copied-node-ID map.
That map includes roots and detached nodes, is scoped to the inspected graphs,
and is one-to-one. Capture correspondence from the actual objects produced by
the copying operation. Do not infer it from names, sorted IDs, node list order,
or equal node counts. A native copying call supplies no documented node-map
return; obtain unambiguous graph correspondence before claiming a full check.
If it cannot be established, report verification incomplete and stop subsequent
assignment/cleanup. Do not guess a map to make verification pass.

For each expected connection, verify:

- The intended source and target IDs resolve in the current destination graph.
- The target input's INTERNAL parameter name is known.
- getInputEdge(parameter=name) returns the edge with those endpoints.
- The same edge appears in the source's output list and target's input list.
- The enabled state matches the expected connection.
- No expected connections are missing and no extra connections exist in the
  verified graph scope.

ShaderEdge.getID() identifies an observed edge. It is not documented as its
input parameter name. Enumerate the target's ShaderParameters, use getName(),
and query getInputEdge() to associate a parameter with an actual edge. A missing
or ambiguous match is unresolved. Some multi-edge inputs may not be fully
exposed by a singular getInputEdge lookup; fail the full verification instead
of inventing a target input or silently omitting such an edge.

Source and destination edge IDs need not be equal. Compare endpoints through
the node map plus the internal input name and enabled state.

## 5. Complete read-only verification helper

This code changes no scene state. It has no dialogs, setters, file operations,
network calls or external dependencies. It works with graphs supplied by the
calling script and prints names only as labels. It checks all enumerated nodes,
roots, input/output edges and mapped target inputs. It explicitly rejects stale,
incomplete and many-to-one maps, including graphs with unaccounted wrapper nodes.

capture_graph(source_graph) is called BEFORE copying. Keep that snapshot and
the map in memory in the same open scene. verify_copy(source_before,
copied_graph, node_id_map) re-reads the source and destination. If copying changes
the source IDs, stop and deliberately recapture/remap from current references;
do not reuse the stale mapping. The helper does not create a map by guessing.

A successful result certifies only the enumerated topology, root correspondence,
shader types and enabled states. Concrete parameter values, textures, external
resources, independent edit behavior and rendered appearance need their own
checks. Structurally interchangeable nodes can carry different values; topology
alone cannot establish that their properties were copied correctly.

```python
"""Read-only post-copy topology verification; run inside KeyShot.

Use capture_graph(source_graph) before copying. Pass that in-memory snapshot,
the newly retrieved target graph, and a complete current source-ID -> target-ID
mapping to verify_copy(). Nothing is matched by node name or list position.
This verifies node types, root membership, target inputs and edge endpoints /
enabled states. It does not compare concrete values or prove copy isolation.
"""

import lux


def sequence(value, label):
    if value is None or not isinstance(value, (list, tuple)):
        raise TypeError("{}: expected a list/tuple, got {!r}".format(label, value))
    return value


def node_id(node: "lux.ShaderNode"):
    if node is None:
        raise ValueError("Missing shader node")
    return node.getID()


def node_data(node: "lux.ShaderNode"):
    raw_type = node.getType()
    if isinstance(raw_type, dict):
        shader_type = raw_type.get("name")
    elif isinstance(raw_type, (list, tuple)) and raw_type:
        shader_type = raw_type[0]
    else:
        shader_type = raw_type
    if not isinstance(shader_type, str) or not shader_type:
        raise ValueError("Unresolved shader type: {!r}".format(raw_type))
    # A blank or duplicate display name is valid; it is not a matching key.
    return node_id(node), shader_type, node.getName()


def edge_data(edge: "lux.ShaderEdge"):
    if edge is None:
        raise ValueError("Missing shader edge")
    return (edge.getID(), node_id(edge.getSourceNode()),
            node_id(edge.getTargetNode()), edge.isEnabled())


def parameter_name(parameter: "lux.ShaderParameter"):
    if parameter is None:
        raise ValueError("Missing shader parameter")
    name = parameter.getName()
    if not isinstance(name, str) or not name:
        raise ValueError("Unresolved internal parameter name: {!r}".format(name))
    return name


def bag(items):
    counts = {}
    for item in items:
        counts[item] = counts.get(item, 0) + 1
    return counts


def inspect_node(node: "lux.ShaderNode"):
    nid, shader_type, label = node_data(node)
    inputs = [edge_data(e) for e in sequence(node.getInputEdges(), "input edges")]
    outputs = [edge_data(e) for e in sequence(node.getOutputEdges(), "output edges")]
    if any(edge[2] != nid for edge in inputs):
        raise ValueError("An input edge targets another node: {!r}".format(nid))
    if any(edge[1] != nid for edge in outputs):
        raise ValueError("An output edge starts at another node: {!r}".format(nid))
    bindings = {}
    errors = []
    names = set()
    for parameter in sequence(node.getParameters(), "parameters"):
        name = parameter_name(parameter)
        if name in names:
            raise ValueError("Duplicate internal parameter key on node {!r}: {!r}".format(nid, name))
        names.add(name)
        try:
            edge = node.getInputEdge(parameter=name)
        except Exception as exc:
            # Some parameters may expose no edge through this getter. Retain the
            # failure as evidence; every actual input edge must still resolve.
            errors.append((name, type(exc).__name__, str(exc)))
            continue
        if edge is None:
            continue
        observed = edge_data(edge)
        if observed not in inputs:
            raise ValueError("Input lookup disagrees with input-edge list: {!r}".format(observed))
        bindings.setdefault(observed, []).append(name)
    resolved = []
    for edge in inputs:
        candidates = bindings.get(edge, [])
        if len(candidates) != 1:
            raise ValueError("Unresolved target input for edge {!r}; candidates={!r}; "
                             "lookup_errors={!r}".format(edge, candidates, errors))
        resolved.append((edge[1], edge[2], candidates[0], edge[3]))
    if errors:
        print("INPUT_LOOKUP_NOTES node_id={!r}: {!r}".format(nid, errors))
    print("NODE id={!r} name={!r} type={!r}".format(nid, label, shader_type))
    return nid, shader_type, inputs, outputs, resolved


def capture_graph(graph: "lux.MaterialGraph"):
    if graph is None:
        raise ValueError("Missing material graph")
    nodes = {}
    incoming = []
    outgoing = []
    connections = []
    for node in sequence(graph.getNodes(), "graph nodes"):
        nid, shader_type, ins, outs, resolved = inspect_node(node)
        if nid in nodes:
            raise ValueError("Duplicate node ID inside one graph: {!r}".format(nid))
        nodes[nid] = shader_type
        incoming.extend(ins)
        outgoing.extend(outs)
        connections.extend(resolved)
        fresh = graph.getNodeFromID(id=nid)
        fresh_id, fresh_type, _label = node_data(fresh)
        if (fresh_id, fresh_type) != (nid, shader_type):
            raise ValueError("Node-ID lookup changed during inspection: {!r}".format(nid))
    if not nodes:
        raise ValueError("Empty material graph")
    if bag(incoming) != bag(outgoing):
        raise ValueError("Input and output edge inventories disagree")
    for _edge_id, source_id, target_id, _enabled in incoming:
        if source_id not in nodes or target_id not in nodes:
            raise ValueError("Edge endpoint is outside the inspected graph")
    roots = [node_id(root) for root in sequence(graph.getMaterialNodes(), "material roots")]
    primary = node_id(graph.getRoot())
    if not roots or len(set(roots)) != len(roots):
        raise ValueError("Missing or repeated material-root IDs")
    if any(root not in nodes for root in roots) or primary not in nodes:
        raise ValueError("Graph/root enumeration disagrees")
    return {"graph": graph, "nodes": nodes, "roots": set(roots),
            "primary": primary, "edges": bag(connections),
            "edge_ids": bag(incoming)}


def verify_copy(source_before, target_graph: "lux.MaterialGraph", node_id_map):
    # Source must still match the captured observation in this open scene.
    current_source = capture_graph(source_before["graph"])
    for field in ("nodes", "roots", "primary", "edges", "edge_ids"):
        if current_source[field] != source_before[field]:
            raise ValueError("Source changed or IDs became stale; recapture and remap")
    target = capture_graph(target_graph)
    if source_before["graph"] == target_graph:
        raise ValueError("Source and destination are the same graph")
    mapping = dict(node_id_map)
    if set(mapping) != set(source_before["nodes"]):
        raise ValueError("Mapping must cover every source node, including roots and detached nodes")
    if len(set(mapping.values())) != len(mapping):
        raise ValueError("Mapping must be one-to-one; two source nodes share a destination ID")
    if set(mapping.values()) != set(target["nodes"]):
        raise ValueError("Mapping must cover every destination node; report added/missing nodes")
    for source_id, target_id in mapping.items():
        if source_before["nodes"][source_id] != target["nodes"][target_id]:
            raise ValueError("Mapped shader types differ: {!r} -> {!r}".format(source_id, target_id))
    if {mapping[root] for root in source_before["roots"]} != target["roots"]:
        raise ValueError("Mapped material roots differ")
    if mapping[source_before["primary"]] != target["primary"]:
        raise ValueError("Mapped primary root differs")
    expected = {}
    for (source_id, target_id, parameter, enabled), count in source_before["edges"].items():
        key = (mapping[source_id], mapping[target_id], parameter, enabled)
        expected[key] = expected.get(key, 0) + count
    if expected != target["edges"]:
        raise ValueError("Copied connections differ: expected={!r}; observed={!r}".format(
            expected, target["edges"]))
    for source_id, target_id, parameter, enabled in expected:
        print("VERIFIED source_id={!r} target_id={!r} input={!r} enabled={!r}".format(
            source_id, target_id, parameter, enabled))
    print("TOPOLOGY VERIFIED: {} nodes, {} connections; values/isolation not tested".format(
        len(mapping), sum(expected.values())))
    return True


if __name__ == "__main__":
    print("Read-only copy verifier loaded; mode={}".format(
        "headless" if lux.isHeadless() else "GUI"))
    print("Call capture_graph(source_graph) before copying, then verify_copy with the live ID map.")
```

## 6. Integration with a working copying script

1. Resolve the exact source graph/root scope and validate new destination names.
   getSceneMaterials() is documented as currently used materials; it is not a
   complete guarantee against collisions with unused material names.
2. Capture the source graph before any changes using the helper above.
3. Run the established copy/manual reconstruction stage. Record correspondence
   from each actual source node to the node created for it, including roots.
   Keep the existing pass; repair its individual API mistakes as listed below.
4. Retrieve the destination graph again. Refresh the source/copy node objects and
   IDs. Use an explicit mapping for the correct roots, not a name-based guess.
5. Call verify_copy before reporting topology success or making later assignment
   changes. On failure, report that a partial copy may remain; there is no
   transaction or automatic rollback. Do not delete original nodes or materials.
6. For "a copy of a copy", repeat the process with the first copy as the source,
   a new destination name and a new mapping. Never reuse the original ID map.
7. After any sub-material linking step, re-query and repeat the verification for
   the resulting intended graph scope. If a new wrapper/root changes the graph
   structure, explicitly account for it; do not drop nodes to force equality.

The OpenPBR converter illustrates retaining the actual connected source node
from getInputEdge(...).getSourceNode() and reconnecting that object to a mapped
input name. It does not match source nodes by display name. Its current v0.5.0
conversion routine is not a general complete Multi-Material copier: it chooses
one supported shader, and its all-root ID collection is used in cleanup guards.
Use that connection-handling pattern without importing unrelated conversion or
cleanup behavior into a copying workflow.

## 7. Corrections to the earlier example

| Earlier pattern | Correction |
| --- | --- |
| Treating a second pass as redundant | Keep the explicit post-copy validation/reconnection pass; check actual resulting edges. |
| parameter.getID() | ShaderParameter has getName(), not getID(). Look up target parameters by their internal names. |
| param_name = str(edge.getID()) | Resolve the target parameter through getParameters()/getInputEdge(). An edge ID string is not evidence of an input key. |
| newNode(node.getType()) | Extract and validate the internal shader type. The repository examples handle a dictionary, not just a scalar type name. |
| Treating all getNodes() entries as ordinary shaders | Handle roots/container nodes explicitly; their correspondence cannot be inferred from names or positions. |
| Copying every parameter's concrete value | Check source/target parameter type and isPure(); pure parameters have no concrete value. Preserve connections separately. |
| Matching or deduplicating nodes by name | Use a graph-scoped current ID/object map. Blank and duplicate node names are valid. |
| Reusing IDs after reopening or linking | Re-query current references and rebuild the map; reject stale snapshots. |
| Converting every sub-material item with str() | Validate the returned representation; do not turn an unknown object representation into a supposed material name. |
| Catching copy errors and continuing to print success | Stop dependent mutations, report incomplete work, and retain the original scene data. |
| Different IDs imply full independence | ID changes do not prove absence of shared resources or independent editing behavior. |

There is no automatic reconstruction/assignment implementation in this guide
that claims to solve unknown root mapping or arbitrary Multi-Material nesting.
The complete helper implements the mandatory integrity pass; integrate it with
the actual copying stage whose node correspondence is known. This is an explicit
boundary of the replacement for the unverified v1.3.6 all-in-one example, not a
claim that copying or its manual pass is unnecessary.

## 8. Runtime acceptance checks and sources

Use a disposable scene with an ordinary material, multiple sub-materials, blank
node names, duplicate node names, shared upstream nodes, detached nodes and a
texture/utility chain. Exercise a copy, a copy of that copy and the intended
sub-material linking operation. Record the exact KeyShot version and mode.

- Verify names are only labels; different same-named nodes retain separate
  current mappings. Root selection must not depend on name uniqueness.
- Deliberately omit an edge or connect it to the wrong same-named node; the
  verifier must reject the result. Check wrong inputs and enabled states too.
- Compare concrete values, parameter types, textures and rendered appearance.
- Edit only the disposable copy and inspect the original to check isolation;
  this observation is separate from topology verification.
- Reopen the disposable scene and rebuild mappings from the newly assigned IDs.
  Do not reuse the prior in-memory mapping. DT has already reported reassignment;
  this check exercises the script's handling of it, not whether to believe it.
- Confirm intended sub-material ordering/active selection and unchanged object
  assignments outside the requested operation.
