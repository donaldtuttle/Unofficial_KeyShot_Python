### Material: Wireframe
  - **SHADER_TYPE**: show_wireframe
  - **apply_bump_to_labels** (BOOLEAN): Determines if bump maps are applied to labels. (Value: False)

  - **base_transmission** (PARAMETER_TYPE_COLOR): Base transmission of the material. (Value: (0.0, 0.0, 0.0))
  - **bumpmap** (PARAMETER_TYPE_TEXTURE): Defines the bump map used for the material. (Value: Pure Parameter)
  - **opacitymap** (PARAMETER_TYPE_TEXTURE): Defines the material's opacity. (Value: Pure Parameter)
  - **opacitymap_mode** (PARAMETER_TYPE_INTEGER): Mode for opacity map. (Value: 2)
  - **width** (PARAMETER_TYPE_FLOAT): Width of the wireframe lines. (Value: 0.5)
  - **width in pixels** (BOOLEAN): Determines if the width is in pixels. (Value: True)
  - **wire_color** (PARAMETER_TYPE_COLOR): Color of the wireframe lines. (Value: (0.0, 0.0, 0.5))

## The Wireframe material type exposes the lines and vertices of each polygon of a surface.

Width
Controls the width of the lines (wires) in the wireframe.

Width in pixels
When enabled, the wires are defined using pixels. When this setting is disabled, the wires are defined using scene units.

Wire Color
This controls the color of the lines of the wireframe
Base Color
This controls the overall color of material, excluding the wires.

Base Transmission Color
This value controls the base color transmission. A lighter color will give the appearance of transparency.

Backside Base Color
This controls the backside of the base color. On a cube this would be the inside of the cube.

Backside Wire Color
This controls the backside of the wire color.
