### Material: Diffuse
  - **SHADER_TYPE**: lux_diffuse
  - **apply_bump_to_labels** (BOOLEAN): Determines if bump maps are applied to labels. (Value: False)
  - **bumpmap** (PARAMETER_TYPE_TEXTURE): Defines the bump map used for the material. (Value: Pure Parameter)
  - **diffuse** (PARAMETER_TYPE_COLOR): The main color of the material. (Value: (0, 0, 0, 1.0))
  - **opacitymap** (PARAMETER_TYPE_TEXTURE): Defines the material's opacity. (Value: Pure Parameter)
  - **opacitymap_mode** (PARAMETER_TYPE_INTEGER): Mode for opacity map. (Value: 2)
  - **roughness** (PARAMETER_TYPE_FLOAT): Controls the sharpness of reflections. (Value: 0.0)

## The Diffuse material type is useful for easily creating any kind of matte or non-reflective material. It has only one setting, the diffuse color. Since it is an entirely diffuse material, specular maps are not available.

Color
This setting controls the color of the diffuse material. Select the color box to display the Color Picker and select the desired color.

The "Diffuse" material is primarily defined by its color, offering a simple, non-reflective surface ideal for objects needing solid, uniform colors without gloss.
