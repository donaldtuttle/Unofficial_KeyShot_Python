# Material graph duplication

Use the explicit walk in lux scripts/duplicate_material_graph.py in the Unofficial_KeyShot_Python repository. lux.createMultiMaterial supplies the named container only. It does not guarantee a deep independent clone.

Recreate the nodes, copy supported non-pure parameter values, and rebuild each connection using its target input parameter name. Read only non-pure source values and write only to matching non-pure destination parameters.

For the procedure and test steps, see lux python scripting guides/KeyShotPythonScripting_MaterialGraph_CopyOfaCopy_Guide.md
