## Chat-GPT: How to Make a zip containing markdown files
```python
import zipfile
import os

# Define the directory you want to zip and the output zip file path
directory_to_zip = '/mnt/data/example_zipfile_name/'
zip_file_path = '/mnt/data/example_zipfile_name.zip'

# Create a zip file (overwrite if it exists)
with zipfile.ZipFile(zip_file_path, 'w', zipfile.ZIP_DEFLATED) as zipf:
    # Walk through the directory
    for root, dirs, files in os.walk(directory_to_zip):
        for file in files:
            # Create a relative path for files to keep the directory structure
            relative_path = os.path.relpath(os.path.join(root, file), os.path.join(directory_to_zip, '..'))
            # Add file to the zip file
            zipf.write(os.path.join(root, file), arcname=relative_path)

# Confirm completion
print(f"Created zip file: {zip_file_path}")
```

## Common Issues Encountered
During the process of developing and refining the KeyShot scripts, several recurring issues were encountered. These issues highlight the typical challenges one might face when scripting in KeyShot and how they were resolved.

- **Error Message**: `TypeError: argument 1 must be str, not list`
- **Cause**: This error often occurred when functions expected a string argument but received a list instead.
- **Solution**: Ensured that only string values were passed where required, particularly when dealing with file paths and template names. Used indexing to extract string elements from lists.

- **Error Message**: `Exception: Default value of a check tuple must be a boolean!`
- **Cause**: Incorrectly formatted tuples in `lux.getInputDialog()`, particularly for selection items (`lux.DIALOG_ITEM` and `lux.DIALOG_CHECK`).
- **Solution**: Verified and corrected the format of dialog tuples, ensuring all required elements were present and correctly formatted.

### Uninitialized Variables
- **Error Message**: Various errors related to uninitialized or empty variables.
