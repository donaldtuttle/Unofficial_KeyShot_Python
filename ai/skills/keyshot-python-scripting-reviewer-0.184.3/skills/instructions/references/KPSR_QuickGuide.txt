Chapter 1: Introduction to KeyShot Python Scripting
1.1 Overview of Python in KeyShot: Python in KeyShot offers the ability to script complex workflows, automate repetitive tasks, and handle dynamic scenes. Unlike standard Python, KeyShot scripting interacts directly with the KeyShot scene graph and its nodes, which are customized objects and not typical Python data types.

I. Introduction to Python in KeyShot
KeyShot Python Overview:

KeyShot uses Python to automate tasks, control rendering, and manage 3D scenes. The integration of the lux module is specific to KeyShot and allows for manipulation of scene nodes, materials, and rendering settings.
Key Difference: Unlike general Python, which includes libraries for tasks like data manipulation, the lux module is specifically optimized for 3D graphics and rendering workflows.

Best Practice 1: Structure Scripts for Modularity

Organize your scripts into functions or classes that can be reused across different projects. Modular code is easier to maintain and test.

Example:

def set_material_color(material_name, color):
    material = lux.getMaterialGraph(name=material_name)
    shader = material.getShaderNode(type="diffuse")
    shader.setParameter("color", color)

# Reuse function across different materials
set_material_color("Cube Material", lux.Color(1, 0, 0))  # Red color

1.2 Setting Up Your Python Environment: To script in KeyShot, ensure you have Python 3.x installed and KeyShot’s lux module available. Scripts can be run directly within KeyShot or in an external Python environment connected via the KeyShot network rendering system.

II. Setting Up Your Python Environment
Setting Up the Environment:

Scripts in KeyShot are run within its own integrated Python interpreter. Save scripts as .py files and run them either directly in KeyShot or through external editors.
Best Practice 2: Test in Small Increments

Avoid writing long, complex scripts in one go. Test each function or block incrementally to isolate bugs early and ensure proper execution.

1.3 Key Differences from Normal Python: KeyShot objects (nodes, materials, graphs) are not native Python types. Functions like lux.getMaterialGraph() return KeyShot-specific objects that must be manipulated using the KeyShot API. Additionally, error handling and logging are more critical in KeyShot Python scripts due to the non-standard data types.

Chapter 2: Understanding the KeyShot Python API
